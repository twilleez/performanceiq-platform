# Legacy / Reference Frontend

This React/Vite application is **not the production PerformanceIQ frontend**.

The authoritative production UI is the repository-root static application (`index.html`, `js/`, and `css/`) deployed by `.github/workflows/deploy.yml`.

This directory is retained only as reference/prototype code so potentially useful concepts are not lost. Do not implement production fixes here unless a Program Manager-approved migration explicitly replaces the root application.

It is excluded from the GitHub Pages deployment artifact and is no longer a root npm workspace.
